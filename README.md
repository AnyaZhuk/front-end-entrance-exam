## Реализованный функционал

*   **Полная редактируемость:** Все текстовые поля на странице можно изменять в реальном времени. Изменения автоматически сохраняются в `localStorage` браузера. 

*   **Сохранение в PDF:** Реализована функция скачивания резюме в виде одностраничного PDF-файла с помощью библиотек `html2canvas` и `jsPDF`.

*   **Адаптивная верстка:** Проект корректно отображается на десктопных, планшетных и мобильных устройствах.
    > **Как проверить адаптивность на GitHub Pages:**
    >     *   Нажмите клавишу `F12`, чтобы открыть инструменты разработчика.
    >     *   В открывшейся панели найдите и нажмите на иконку телефона/планшета (обычно слева вверху).
    >     *   Теперь вы можете выбрать любое мобильное устройство из списка вверху (например, iPhone 12 Pro или Pixel 5), чтобы увидеть, как сайт выглядит на нем.

*   **Интерактивные анимации:**
    *   **Эффект редактирования:** При клике на текстовое поле оно подсвечивается белым фоном и серой рамкой для удобства.
    *   **Анимация сохранения:** После завершения редактирования поле "пульсирует", подтверждая сохранение изменений.
    *   **Material Wave (Ripple) Effect:** При клике на интерактивные блоки (карточки, кнопки) расходится эффект "волны", улучшая пользовательский опыт.

*   **Сброс изменений:** Кнопка "Сброс" позволяет очистить `localStorage` и вернуть резюме к первоначальному состоянию.

*   **Развертывание на GitHub Pages:** Проект полностью настроен для быстрой и удобной публикации в интернете.

## Стек технологий
*   HTML5
*   CSS3 (Flexbox, Grid, Animations, Custom Properties)
*   JavaScript (ES6+)
*   Библиотеки: `html2canvas`, `jsPDF`
